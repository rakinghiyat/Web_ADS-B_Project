# Web_ADS-B_Project

**Web_ADS-B_Project** is a centralized web-based monitoring application for ADS-B (Automatic Dependent Surveillance–Broadcast) Ground Stations, specifically designed for use within a Flight Information Region (FIR). Built with **CodeIgniter 4**, this project emphasizes speed, modularity, and ease of managing data from multiple monitoring stations.

## ✈️ Key Features

- Real-time monitoring of ADS-B Ground Station status
- Connectivity and performance statistics dashboard
- Ground Station data management (location, status, activity logs)
- Role-based user authentication system
- Admin panel for configuration and monitoring

## 🧱 Technologies Used

- **Backend:** PHP 8.x + CodeIgniter 4
- **Frontend:** HTML5, Bootstrap, jQuery
- **Database:** MySQL / MariaDB
- **Deployment:** Apache/Nginx, Linux Server

## 🚀 Getting Started (Local Development)

1. Clone the repository:
   ```bash
   git clone https://github.com/rakinghiyat/Web_ADS-B_Project.git
   cd Web_ADS-B_Project
2. Copy the environment file:
   ```bash
   cp env .env
3. Configure your database credentials inside `.env`
4. Run the development server:
   ```bash
   php spark serve
5. Access the app in your browser:
   `http://localhost:8080`
